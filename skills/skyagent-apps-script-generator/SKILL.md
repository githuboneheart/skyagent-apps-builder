# SkyAgent Apps Script Generator — Pembuat Kode Aplikasi

## Tujuan

Menghasilkan kode Google Apps Script lengkap yang siap deploy, berdasarkan PRD dan UI Plan yang sudah disetujui member. Kode harus modular, bersih, dan sesuai batasan Apps Script.

## Prasyarat

Sebelum generate kode, pastikan:
- ✅ PRD lengkap (17 bagian) sudah disetujui member
- ✅ UI Plan sudah dikonfirmasi
- ✅ Member sudah menekan tombol "Proses"

## Struktur File Standar

```
📁 Google Apps Script Project
├── Code.gs                 # Entry point, doGet(), routing
├── Setup.gs                # Inisialisasi sheet, header, data awal
├── Auth.gs                 # Login, registrasi, session management
├── Database.gs             # CRUD operations, query helper
├── [Module].gs             # Modul per fitur (Product.gs, Transaction.gs, dll)
├── Utils.gs                # Utility functions (format tanggal, generate ID, dll)
├── Config.gs               # Konfigurasi aplikasi (nama app, versi, dll)
├── Index.html              # Template utama (layout, navigasi)
├── Style.html              # CSS global
├── Script.html             # JavaScript global
├── Components.html         # Komponen reusable (modal, toast, loader)
├── [Page].html             # Halaman per fitur
└── appsscript.json         # Manifest
```

### 3. Setup.gs — Inisialisasi

```javascript
/**
 * Setup — Inisialisasi sheet dan data awal
 * Jalankan fungsi ini SEKALI setelah deploy pertama
 */

function setupApplication() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();

  // Daftar sheet yang akan dibuat (dari PRD bagian 10)
  const sheets = [
    {
      name: '[Nama Sheet]',
      headers: ['id', 'kolom1', 'kolom2', '...'],
      widths: [150, 200, 200]
    },
    // ... tambahkan sesuai PRD
  ];

  sheets.forEach(sheetConfig => {
    let sheet = ss.getSheetByName(sheetConfig.name);
    if (!sheet) {
      sheet = ss.insertSheet(sheetConfig.name);
    }

    // Set headers
    if (sheet.getLastRow() === 0) {
      sheet.appendRow(sheetConfig.headers);
      const headerRange = sheet.getRange(1, 1, 1, sheetConfig.headers.length);
      headerRange.setFontWeight('bold');
      headerRange.setBackground('#4a90d9');
      headerRange.setFontColor('#ffffff');
    }

    // Set column widths
    sheetConfig.widths.forEach((width, index) => {
      sheet.setColumnWidth(index + 1, width);
    });

    // Freeze header row
    sheet.setFrozenRows(1);
  });

  // Setup data awal (admin default, dll)
  setupDefaultData_(ss);

  SpreadsheetApp.getUi().alert('✅ Setup berhasil! Aplikasi siap digunakan.');
}

function setupDefaultData_(ss) {
  // Admin default
  const usersSheet = ss.getSheetByName('Users');
  if (usersSheet && usersSheet.getLastRow() <= 1) {
    usersSheet.appendRow([
      generateId_(),
      'admin@example.com',
      hashPassword_('admin123'),
      'Administrator',
      'admin',
      new Date(),
      'active'
    ]);
  }
}
```

### 4. Auth.gs — Autentikasi

```javascript
/**
 * Auth — Login, session management
 */

function login(email, password) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName('Users');
  const data = sheet.getDataRange().getValues();

  for (let i = 1; i < data.length; i++) {
    if (data[i][1] === email && data[i][2] === hashPassword_(password)) {
      if (data[i][6] !== 'active') {
        return { success: false, message: 'Akun tidak aktif. Hubungi admin.' };
      }

      const token = generateToken_();
      const userProps = PropertiesService.getUserProperties();
      userProps.setProperty('session_token', token);
      userProps.setProperty('session_user', JSON.stringify({
        id: data[i][0],
        email: data[i][1],
        name: data[i][3],
        role: data[i][4]
      }));

      return {
        success: true,
        message: 'Login berhasil!',
        user: {
          name: data[i][3],
          role: data[i][4]
        },
        token: token
      };
    }
  }

  return { success: false, message: 'Email atau password salah.' };
}

function logout() {
  const userProps = PropertiesService.getUserProperties();
  userProps.deleteAllProperties();
  return { success: true };
}

function getCurrentUser() {
  const userProps = PropertiesService.getUserProperties();
  const userJson = userProps.getProperty('session_user');
  if (!userJson) return null;
  return JSON.parse(userJson);
}

function checkAuth() {
  const user = getCurrentUser();
  if (!user) {
    return { authenticated: false };
  }
  return { authenticated: true, user: user };
}
```

### 5. Database.gs — CRUD Helper

```javascript
/**
 * Database — CRUD operations helper
 */

function getSheetData(sheetName, filters) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName(sheetName);
  if (!sheet || sheet.getLastRow() <= 1) return [];

  const data = sheet.getDataRange().getValues();
  const headers = data[0];
  let results = [];

  for (let i = 1; i < data.length; i++) {
    const row = {};
    headers.forEach((header, index) => {
      row[header] = data[i][index];
    });

    if (filters) {
      let match = true;
      for (const [key, value] of Object.entries(filters)) {
        if (row[key] !== value) {
          match = false;
          break;
        }
      }
      if (!match) continue;
    }

    row._rowIndex = i + 1;
    results.push(row);
  }

  return results;
}

function insertRow(sheetName, rowData) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName(sheetName);
  const headers = sheet.getRange(1, 1, 1, sheet.getLastColumn()).getValues()[0];

  const row = headers.map(header => rowData[header] || '');
  sheet.appendRow(row);

  return { success: true, id: rowData.id };
}

function updateRow(sheetName, id, updates) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName(sheetName);
  const data = sheet.getDataRange().getValues();
  const headers = data[0];

  for (let i = 1; i < data.length; i++) {
    if (data[i][0] === id) {
      for (const [key, value] of Object.entries(updates)) {
        const colIndex = headers.indexOf(key);
        if (colIndex >= 0) {
          sheet.getRange(i + 1, colIndex + 1).setValue(value);
        }
      }
      return { success: true };
    }
  }

  return { success: false, message: 'Data tidak ditemukan.' };
}

function deleteRow(sheetName, id) {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const sheet = ss.getSheetByName(sheetName);
  const data = sheet.getDataRange().getValues();

  for (let i = 1; i < data.length; i++) {
    if (data[i][0] === id) {
      sheet.deleteRow(i + 1);
      return { success: true };
    }
  }

  return { success: false, message: 'Data tidak ditemukan.' };
}
```

### 6. Utils.gs — Utility

```javascript
/**
 * Utils — Fungsi-fungsi pembantu
 */

function generateId_() {
  return Utilities.getUuid();
}

function generateToken_() {
  return Utilities.getUuid() + '-' + new Date().getTime();
}

function hashPassword_(password) {
  const rawHash = Utilities.computeDigest(
    Utilities.DigestAlgorithm.SHA_256,
    password
  );
  return rawHash.map(b => ('0' + (b & 0xFF).toString(16)).slice(-2)).join('');
}

function formatCurrency(amount) {
  return 'Rp ' + Number(amount).toLocaleString('id-ID');
}

function formatDate(date) {
  if (!date) return '-';
  const d = new Date(date);
  return Utilities.formatDate(d, 'Asia/Jakarta', 'dd/MM/yyyy HH:mm');
}

function formatDateShort(date) {
  if (!date) return '-';
  const d = new Date(date);
  return Utilities.formatDate(d, 'Asia/Jakarta', 'dd/MM/yyyy');
}
```

## Panduan Generate Kode

### Langkah 1: Mapping PRD ke File

Baca PRD dan mapping setiap bagian ke file yang sesuai:

| Bagian PRD | File Target |
|-----------|-------------|
| Struktur Sheet (10) | Setup.gs |
| Role & Auth (5) | Auth.gs |
| Fitur Wajib (7) | [Module].gs + [Page].html |
| Halaman UI (11) | [Page].html |
| Aturan Bisnis (12) | Validasi di [Module].gs |
| Laporan (13) | Report.gs + Report.html |
| UI Plan (6) | Style.html + layout di Index.html |

### Langkah 2: Generate Server-side Dulu

Urutan pembuatan file server-side:
1. `appsscript.json` — manifest
2. `Config.gs` — konfigurasi
3. `Utils.gs` — utility
4. `Setup.gs` — inisialisasi sheet
5. `Auth.gs` — autentikasi
6. `Database.gs` — CRUD helper
7. `[Module].gs` — satu file per domain fitur
8. `Code.gs` — entry point (terakhir, karena perlu tahu semua routing)

### Langkah 3: Generate Client-side

Urutan pembuatan file client-side:
1. `Style.html` — CSS sesuai UI Plan (warna, font, layout)
2. `Components.html` — komponen reusable
3. `Index.html` — template utama dengan layout
4. `Script.html` — JavaScript global
5. `[Page].html` — satu file per halaman

### Langkah 4: Validasi Silang

Setelah semua file dibuat, validasi:
- ✅ Setiap fungsi server-side yang dipanggil dari client ada di file .gs
- ✅ Setiap nama sheet yang direferensikan ada di Setup.gs
- ✅ Setiap halaman di routing ada file HTML-nya
- ✅ Setiap role di Auth.gs sesuai PRD bagian 5
- ✅ CSS menggunakan palet warna dari UI Plan

## Aturan Kode

### WAJIB:
1. Gunakan **V8 runtime** (ES6+ syntax)
2. Semua komentar dalam **bahasa Indonesia**
3. Penamaan variabel/fungsi yang **deskriptif**
4. Setiap file punya **header komentar** (nama, fungsi, tanggal)
5. Error handling di setiap fungsi yang berinteraksi dengan sheet
6. **Validasi input** di server-side, bukan hanya client-side
7. **Responsive CSS** — mobile-first atau desktop-first sesuai UI Plan
8. **Loading state** — tampilkan loader saat proses berlangsung
9. **Toast/notification** — feedback setelah aksi berhasil/gagal
10. **Konfirmasi** — dialog konfirmasi sebelum hapus data

### JANGAN:
1. Jangan gunakan library eksternal yang tidak didukung Apps Script
2. Jangan hardcode data sensitif (password admin, dll) — gunakan Setup.gs
3. Jangan buat query yang bisa timeout (> 50.000 baris tanpa pagination)
4. Jangan simpan password dalam plain text
5. Jangan abaikan validasi — selalu validasi di server-side
